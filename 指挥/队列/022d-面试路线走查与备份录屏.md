# 任务 022d：按面试讲解路线全站走查、数字一致性审计、"本轮经验"、备份录屏（不调用模型，自动值班）

用户已授权：中间所有确认默认同意，不要停下来等人。在 022c 之后执行。原有已跑通的功能和按钮一个都不能坏。

## 背景
demo 要拿去面试现场讲 15–25 分钟。总指挥作为审核人认为，现在最大的风险已经不是"缺功能"，而是以下三类：
1. **讲到某一页时出现前后不一致的数字或残留的内部词**，被面试官当场问住；
2. **页面加载慢、出现空状态或报错**；
3. **现场网络或接口出问题却没有备份。**

本任务专门消除这三类风险，并补上故事里最缺的一块"本轮经验"。

## 1. 进化路线每轮加一行"本轮经验"（故事最缺的一环）
- **现状**：每轮只有"本轮没有合格 Candidate：3 个新增了 Bad Case、1 个没过 Hard Gate"这类计数，看不出这一轮**学到了什么**。
- **数据来源**：**只能**来自已保存的数据，不许编。
  - 优先用下一轮 Agent 推理里引用前一轮结果的原句（每轮 Agent 会拿前面的结果作为客观事实）；
  - 其次用本轮三套方案各自的修好 / 弄坏 / 没过门槛事实，由程序拼成一句客观总结。例如"分级回答的两套都使安全拒答降到 90%"，必须能从数据核对。
- **呈现**：每轮标题下一行浅灰小字，前缀"本轮经验："，最多 40 字，悬停看完整原句和出处（第几轮哪套方案的推理）。
- **找不到来源就不显示**，在报告里写明哪一轮没有。
- **报告**：逐轮列出显示的文字和来源原句，总指挥会逐条核对。

## 3. 按面试路线走一遍，逐站截图并检查
**路线**（1440×900，按顺序）：
1. 概览（首屏 + 讲解区）→ 业务架构页签
2. 知识库（知识处理链路、知识主题覆盖）
3. Golden（摘要、筛选"负向"、打开 Q45 和 Q04 抽屉）
4. Pipeline（参数区）
5. Baseline 报告 → Hard Gate → Bad Case 诊断（点检索层）
6. Agent 进化路线（Round 1 → 2 → 3 → D）→ A/B/C/D 底部 D 决策区 → Regression Check → 最终推荐
7. 发布
8. 问答验证 Before/After（Q04 → Q24 → Q38）→ 实时问答（**只看界面，不发送问题**）→ 线上反馈

**每一站检查**：
- **残留词**：导入、内部、试跑、复跑、随机、不稳定、MEDIUM、FULL、run_、EXP-、MON-、原始时间戳、"未记录 / 暂无 / 未知"等。页面作者写的文字一律清理；题目原文和模型回答原文里本来就有的不改。
- **术语中英文是否全站一致**：同一个概念不能一页英文、一页中文。例如"Generation"已改为"回答生成"，就全站统一。拿不准的列出来，不擅自改。
- **切换页面、页签的等待时间**：超过 1 秒的列出来，并说明原因。
- **空状态、报错、按钮失效**。

**报告**：每站一行，写"截图路径 / 发现的问题 / 处理"。能修的直接修（只改前端展示），不能修的列出。
