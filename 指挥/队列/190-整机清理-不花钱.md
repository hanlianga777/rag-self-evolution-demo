## 二、磁盘
1. 清理前记录 `df -h /`。
2. 找出用户目录下最大的 30 项，重点查以下位置：
   - **本项目内部**：
     - 旧的知识库、索引版本（不是当前激活的，也没有被 M1 冻结题卷、Baseline `EVAL-20261120213645613191`、旧实验 `EXP-20261120224619556715` 或新实验引用）；
     - 旧的评测、临时导出和截图；
     - `backend/data` 下的备份：同类最多保留最近 2 份，回滚点不算在内；
     - 日志、`__pycache__`、`.pytest_cache`、`node_modules/.cache`、前端构建产物 `dist`；
     - 临时数据库和测试残留。
   - **全机**：
     - `~/.cache`（huggingface、torch、pip 等；本项目当前在用的向量和 OCR 模型不删）；
     - `~/Library/Caches`；
     - Chrome 缓存（只清 Cache 和 Code Cache，**不动**登录状态、Cookie、书签）；
     - Playwright 浏览器的旧版本；
     - `/tmp`、`/private/var/folders` 里的临时文件；
     - brew、pip、npm、conda 缓存（`brew cleanup`、`npm cache clean --force`、`pip cache purge`）；
     - Xcode DerivedData；
     - Codex 和 ChatGPT 的会话缓存（只清 Cache 类目录，不动配置和账号）。
3. 删除原则：
   - 引用关系查不清的，不删，列进报告；
   - 删除之前，先确认这个东西没有被当前 demo 引用：启动 demo，打开主要页面不报错；
   - 删完再启动一次 demo，跑一遍主链路页面检查。
4. 清理后再记录一次 `df -h /`。
