# 任务 014a0：今天的值班不在 17:30 收工，自动接力到夜里（不花钱，几分钟就做完）

用户要求：今天的值班不要自己停，只有用户在 Claude 窗口里说"暂停"才停。总指挥会通过推送 `指挥/暂停` 文件来暂停。这个要求只限今天。

现在运行的值班脚本是早上用默认设置启动的：17:30 以后不开新任务，18:30 强制收工，然后退出。本单要安排一个"接力"：等现在这个值班脚本退出后，自动用 `--全权限 --until 2359` 重新启动一个，让值班一直持续到今天夜里。

## 做法
1. 找到当前正在运行的值班脚本进程（`bash 指挥/自动值班/值班.sh --全权限`）的 PID，记为 OLD。注意不要匹配到 Codex 自己或别的进程。
2. 安排一个**不随 Codex 结束而被杀掉**的后台任务。优先用 `launchctl submit -l com.rag.duty.relay -- /bin/bash -c '...'`；不行再用 `nohup ... </dev/null >日志 2>&1 & disown`。这个后台任务要做的是：
   - 每 60 秒检查一次 OLD 是否还在，直到它退出；
   - OLD 退出后：`cd` 到项目目录，`git pull`，然后执行 `bash 指挥/自动值班/值班.sh --全权限 --until 2359 --接手`；
   - 输出写到 `~/RAG归档/值班日志/接力-20261103.log`。
3. 用 `launchctl list | grep com.rag.duty.relay` 或 `ps` 确认这个后台任务已经在等待。
4. 不要停掉、不要重启现在的值班脚本，也不要碰本项目后端。

## 报告
写到 `指挥/报告/014a0-值班接力.md`：OLD 的 PID、用了哪种方式安排接力、怎么确认它在等待、日志路径，以及需要时怎么手动取消它（例如 `launchctl remove com.rag.duty.relay`）。

## 自动值班约束
- 不要运行 git add / commit / push 等修改仓库的命令；
- 不改 `指挥/当前任务.md`。

## 完成后
用普通的 `mv` 把本任务单移到 `指挥/历史任务/`。
