# 127a：每轮必须跑满 A/B/C，D 只能放在最后，支持继承前两轮新开实验（不花钱）

- **依据**：用户 11-27 20:57～21:0x 拍板：
  1. 累计改动上限**保持 4 项**；
  2. **每一轮 A、B、C 三个方案都必须跑完**；
  3. Candidate D 由 Agent 在**最后**自行决定是补跑、综合合并，还是不跑，**不能夹在轮次中间**；
  4. 从第 3 轮开始重跑。第 3 轮的 Agent 只综合 E8 第 1、2 轮的经验重新生成方案，**不能使用 E8 的 D、第 3 轮、第 4 轮的任何数据**。
- **授权**：用户全权授权，总指挥代用户确认。中途不停。
- **费用**：0。只改代码和测试，测试一律用模拟 Provider。
- **决策版本**：`127a`，在 126c 的基础上修改。126c 实验保持原样。

## 1. 每轮必须跑满 3 个

- 每一轮的规划必须给出 A、B、C 三个合法方案，并且三个都进入 Sandbox，评测完成后才能复盘。
- 提案少于 3 个，就按 S17 把拒绝原因反馈给 Agent 重提，不限次数。连续 3 次被拒后改为逐项结构化填写。不允许以「没有好假设」为理由少跑。
- 合法的未试配置不够 3 个时，程序在白名单内列出所有未试取值，以及「撤销 / 替换已有参数」的动作，让 Agent 选出 3 个不重复的配置。
- 复盘前检查三个 Sandbox 是否都有最终判定，缺一个就继续跑或续跑，不进入复盘。

## 2. D 只能在最后

- **删除**轮次中途的「试 D」合法动作，涉及 S4、S5、S8 里的 d 选项。中途发现的互补机会只记入账本，留到最后用。
- **最后阶段**：当以下条件都成立时，进入「最终阶段」：
  - 已经有合格的 Winner；
  - 剩余错题的待试工具已经清空，或者剩余错题已经标为能力边界；
  - 有错题的层都已经探索过；
  - 已进入平台期，即最近一轮没有新的晋升。
- **最终阶段只有三个合法动作，由 Agent 选择并写理由**：
  1. `d_retry` 补跑：拿账本里某个「有收益、有副作用」的改动，配上缓解措施再验证；
  2. `d_merge` 综合合并：合并主线和账本中的互补改动；
  3. `d_skip` 不跑：写明没有可组合项的理由。
- **D 的规则**：
  - 只跑 1 次 Sandbox；
  - 累计改动不超过 4 项；
  - 晋升条件与 Winner 相同：保住全部已有成果，并且有严格增量。
- **D 跑完后立即结束**：D 晋升就发布 D，否则发布 Winner。D 之后不再开新轮。
- 满分时可以直接结束，不做 D。

## 3. 继承前 N 轮新开实验

- 新增接口或脚本：从已完成的实验 X 复制前 N 轮，开一个新实验。复制的内容：
  - 这几轮的候选、Sandbox 评测、三层标签、复盘；
  - 只属于这几轮的经验账本和预测对账。
- **不复制**：第 N 轮之后的任何候选和评测、任何 D 提案与结果、之后的 Winner 和支线。请求复用缓存只能读取复制过来的这几轮的请求。
- **底座**：新实验的 Winner 和支线，按复制来的前 N 轮重新计算。如果 N=2，按 E8 第 1、2 轮的结果，Winner 应为 R1-B（45/50），第 2 轮没有晋升。
- **前端**：复制来的轮次照常显示，详情里注明「沿用自 E8 第 n 轮」。

## 4. 测试（模拟数据，零费用，必须全部通过）

1. 少于 3 个提案时必须被拒绝重提，三个都跑完才进入复盘。
2. 中途 S4、S5 的合法动作里不再出现 D；只有满足最终阶段条件时，才出现 `d_retry`、`d_merge`、`d_skip`。
3. D 跑完后直接收尾发布，不再开新轮。
4. 继承前 2 轮：新实验的 Winner、账本、预测对账只包含前 2 轮；第 3 轮及以后的数据、D 的数据对新实验不可见，包括请求复用缓存。
5. 端到端模拟演练：继承 2 轮 → 第 3 轮 → 第 n 轮 → 最终阶段 → D 或不做 D → 发布。
6. 一律用临时库，并显式传入临时库路径。
