## 1. 一屏刚好放下（用户第 5 条）
**标准**：用户认为 Golden Dataset「当前测试集」是最好的样子。在 1440×900 下：
- 页面本身不滚动，卡片正好铺到屏幕底部；
- 长列表在卡片内部滚动。

**以下页签都要做到同样效果**：
- 概览 → 项目概览
- Pipeline 配置
- Golden → 候选池
- Baseline → Baseline 报告、Hard Gate、Bad Case 诊断（列表在卡片内滚动，行高收紧）
- 发布
- 问答验证 → 实时问答、Monitoring

**做法**：
- 主内容区高度 = 视口高度减去页头和页签；
- 最后一张卡用 flex 撑满剩余高度；
- 内容放不下的列表、表格在卡内滚动；
- 卡片间距、内边距可以适当收紧。

**检查**：用 027a 的 fit-check 脚本，在 1440×900 和 1280×800 下记录每个页签"页面滚动高度 / 视口高度"，必须 ≤ 1.00。报告里给出前后对照表。

## 2. 按钮样式（用户第 10 条）
- **页面内的重要操作按钮用实心蓝主按钮**，样式与概览"去问答验证"一致：实心蓝底、白字、可带白色图标。例如：
  - Golden 的"运行 Probe""运行 QC"；
  - 发布页、Agent 工作台里真正需要人点的执行类操作。

  每个视口内实心蓝按钮以 1–2 个为限（027a 写的"最多 1 个"以本单为准放宽）。
- **页头右上角按钮一律用"新增文档"那种白底细边次要按钮**，例如"新增文档""参数说明""历史版本""查看历史实验""重建 Knowledge Pipeline"，全站统一高度、字号、圆角，不能抢故事的视觉焦点。
- 报告里列出全站实心蓝按钮清单。

## 3. 页签不记忆（用户第 11 条）
- 从左侧导航切到某个一级页面时，一律打开第一个页签。不要记住上次停留的页签，包括 `usePageTab` 一类的本地存储记忆。
- 例外：地址里明确带了 `tab=` 参数时（例如页面内的跳转按钮），按参数打开。
- 测试覆盖两种情况：从导航进入，回到第一个页签；带参数进入，打开指定页签。

## 4. 删掉页签下和卡片里的废话小字（用户第 4、13 条）
- 每个页签内容最上方那一行说明小字，例如 Hard Gate 的"11 / 11 项通过；每项独立判断，综合分不能抵消未通过的 Hard Gate"，全站逐页检查。复述数字、复述规则的一律删掉，下面的卡片往上顶，不留空行。
- 卡片里同类的备注性小字也一并检查：一眼能看懂的删掉。
- 保留的标准：讲解时确实需要、且页面别处没有出现过。
- 报告里给出完整删除清单（页面、原文）和保留清单（页面、原文、保留理由）。
