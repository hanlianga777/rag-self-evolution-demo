## 本单范围（方案 #12、#13、#14、#15）
1. **#12 知识处理链路**：通用版，不出现任何数字。顺序：解析去噪 → 按章节组 Parent → Parent 内切 Child → 向量 + 关键词索引 → K-means 主题簇。每步一句人话。
2. **#13 分块诊断**：一张小卡，显示当前知识库的真实分块健康指标：
   - 碎块数；
   - 平均每个 Parent 的 Child 数；
   - 单 Child Parent 占比；
   - Child 平均长度。

   要求：
   - 数据由后端只读接口从当前知识库计算，不写死。
   - 每项加"i"说明为什么重要，例如"一个 Parent 至少包含几个 Child，检索才能做到小块命中、大块回答"。
3. **#13 分块浏览器**：替换现有"查看分块示例"，用一个宽抽屉或独立视图，三栏：
   - **左**：选文档 → 章节 / Parent 列表，显示标题和 Child 数。
   - **中**：Parent 原文全文，每个 Child 的范围用交替的浅色底标出，悬停显示"Child 2 / 4"。重叠部分要能看出来。
   - **右**：这个 Parent 被哪些考题命中。每题显示题号、题型、命中的是哪个 Child；点击题目，高亮中间对应的 Child，并可打开该题抽屉。
   - 数据来源是知识库分块和 Golden 证据锚点。需要的只读接口自己加。
4. **#14 知识主题抽屉**重排为三段：
   - 主题是什么：一句话加关键词；
   - 包含哪些 Parent：点开进入分块浏览器并定位；
   - 对应哪些考题：按正向 / 消融 / 负向分组。
5. **#15 文档类别列**：清洁机器人说明书 / 巡检机器人说明书 / 遥控器说明书 / 电池与充电器说明书 / 其他。
   - 按文档标题关键词归类，规则集中写在一处；
   - 报告里列出每份文档的归类结果，方便总指挥核对。
