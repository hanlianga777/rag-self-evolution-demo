扫描脚本也改了：除了单参数和两两组合，现在固定补扫"Top-K=6 + 一个召回类参数"的组合，共 6 个：candidate_k=24、multi_query=4、问题拆解、HyDE、改写、min_score=0.2。原因是 Top-K=4 会把召回变多的收益全部挡住。

2. 导入 dry-run（只校验，不写库）：

   ```
   PYTHONPATH=backend python3 backend/scripts/retrieval_headroom.py --csv 指挥/报告/085-题卷v4.csv --output 指挥/报告/085-检索扫描.csv
   ```

4. 用输出 CSV 判定是否达标（只读计算）。
   - **A**：`baseline_gap` 中正向题 ≥ 4 道。

     - 补回 ≥ 8 道，即 Baseline ✗ 变成 ✓；
     - 弄丢 ≤ 1 道，即 Baseline ✓ 变成 ✗。

   为每一列写出：补回几道（正向几道、消融几道）、弄丢几道。按补回数从高到低列前 8 列。

5. 对每道 `baseline_gap` 题，贴出 CSV 最后一列（Baseline 最终资料）。
