# 121d 知识库、Golden Dataset（含题目抽屉）、Pipeline 配置（不花钱）

前置：121b 已通过总指挥验收。先读 `00-共同规范.md`。只改 `frontend/`。

## 知识库

1. **文档表**列为：短文档名、设备型号、页数、处理状态、操作。
   - 长名字不撑开表格；
   - 表头 sticky，滚动时不消失。
2. **文档分类全是「其他」的问题**：
   - 先查后端有没有分类字段：有就投影出来，没有就隐藏这一列。
   - 结论写进报告，不改后端。
3. **Parser / Embedding 等技术选型**不放首屏，移到 Pipeline 页或折叠区。

## Golden Dataset

1. **当前测试集表格**
   - 「主题簇 / 出处 / 出题方式」按 UI-01 P14 的结论，投影冻结题已保存的 `business_topic`、`business_group`、`generation_method`；
   - 投影后仍然整列为空的，就隐藏该列；
   - 「考查环节」整列相同、没有区分度时，隐藏。
2. **题目抽屉**用 `DrawerShell`，顺序为：
   1. 题目：题号、题型、完整原文；
   2. 参考答案（`RichContent`）。负向题改为「预期行为」；
   3. 核心证据：短文档名 + 页码 + 原文，关键句可以高亮；
   4. 辅助引用；
   5. 题目质量检查：一行结论，必要时附说明；
   6. 技术记录（默认折叠）：冻结版本、Chunk ID、原始合同。
3. **去掉黑色超大 Tooltip**，长内容改为点击展开。

## Pipeline 配置

1. **按四个模块分区**：Query 查询增强 / 检索召回 / 筛选排序 / 生成。
   - 每个参数显示：中文主名 + 代码名、当前值、可选值。
   - 用「Agent 可调」「固定」两种小字区分参数性质。
2. **只显示现行选项**：
   - Thinking 只有 Off / Low / High；
   - Prompt Strategy 只有 Strict / Looser / Safe。
   - 如果后端接口仍然返回旧选项，前端过滤掉，并在报告里写明后端位置，留待后端单处理。
3. **固定技术选型**（Parser、Chunk、Embedding、模型）放在独立的简洁参数区。
4. **安全护栏**还没实现，**不显示**。
5. **配置版本标注**：页面必须标明当前看的是哪个配置版本（线上 / Baseline），不能混用。
