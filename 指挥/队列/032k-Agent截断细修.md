# 032k：Agent 工作台截断细修（总指挥看完 032i 实际页面后）

**授权**：用户已授权，不需要停下来等确认。

032i 的结构已经对了，但截断是**按固定字符数**做的，宽的地方也只显示约 30 个字就出现"…"。例如：

- "带入下一轮的经验"每条占满整行宽度，却只显示"R3-B是唯一合格 Candidate：HyDE组合下Q29、Q41、Q…"，右边空着一大半；
- 截断会切在题号中间（"Q…"）或数字中间。

## 要做的事

1. **改成按"可见行数"截断**，用 CSS 多行省略（`-webkit-line-clamp` 或同等方案）：
   - 卡片内字段最多 2 行；
   - "上一轮总结"每行和"带入下一轮的经验"每条 1 行；
   - 宽度够就多显示，窄窗口自动少显示。

   完整文字仍然通过悬停或键盘聚焦查看。
2. **如果某处必须按字符截断，不许切在题号、数字、英文单词中间**：退回到前一个标点或空格。
3. **字符数验收口径调整**：
   - 032i 的 innerText 字符数指标改为统计"肉眼可见文字"，即被 line-clamp 隐藏的部分不算；
   - 报告里同时给出 innerText 和可见文字两种数字；
   - 目标仍是可见文字低于 032i 改前的 40%。
4. 1440×900、1280×800 截图检查 Round 1 / 2 / 3 / D。宽行要填满再省略，窄窗口不溢出、不重叠。
5. 全量前端测试、`npm run build` 通过，不删测试、不加 skip。收尾确认 5174 提供的是最新构建。
