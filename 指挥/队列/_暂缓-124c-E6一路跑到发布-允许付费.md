## 要做的事

1. **新建实验 E6（初始模式）**：
   - Baseline 用 124b 确认的那份；
   - 不沿用 E1～E5 的任何候选或历史账本；
   - 规则按新版本执行：
     - 目标层选择用 122f 的四层 + 朋友严重度；
     - Agent 用 123b 的两段式规划：先写假设，再定向检查，每轮最多 6 组；
     - Winner 累积门；
     - D 的触发条件；
     - 累计改动最多 3 项；
     - 最多 4 轮、12 次 Sandbox，其中预留 1 次给 D；
     - Sandbox 只复核有变化的题。
2. **执行方式**：全程走统一编排，中途不停。
   - 生成诊断在 Agent 申请后由编排器自动执行；
   - 网络瞬断自动恢复；
   - 只有遇到互审 56 列出的「必须停」情况才停：预算、身份、规则连续被拒、鉴权。
3. **结束后**：
   - D 晋升，则推荐 D；否则推荐最终的 Winner；
   - 对推荐方案做独立的最终复测，单独留记录。
4. **Gate 3 发布**（总指挥代用户确认）：
   - 推荐方案通过复测，且与线上配置不同 → 发布；
   - 与线上配置相同 → 不发布，在报告里说明。
   - 发布前做回滚演练，必须显式指定临时数据库，严禁连接正式库（互审 47）。
   - 发布后确认回滚点存在。
5. **遇到「必须停」的情况**：保存断点，写报告说明原因，然后结束。总指挥会发修复单，之后从断点续跑。
