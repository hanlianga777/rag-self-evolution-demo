## 页面怎么排（总指挥定稿，照此实现）

从上到下：

### ① 题目栏
- 内容：短题号 + 题目原文，加一条判定变化，例如"**优化前：答错 → 优化后：答对**"。用徽章显示，答对用唯一的那种绿色，答错用现有的风险色。

### ② "这道题为什么变好"摘要卡（通栏，1–3 行大白话）
按保存数据自动生成**因果链**："哪个配置变化 → 证据位置怎么变 → 补上了哪条必答要点"。例如：

> 查找候选条数 12→24：说明书里"不得未稀释使用推荐的洗涤剂"这段，从没进入候选，变为排第 1 位 → 回答补上了必答要点"不得未稀释使用"。

没有变化或数据缺失的环节写"未知"或省略，**不编**。

### ③ 左右两栏回答（等高，回答正文在栏内滚动）
- 栏头：方案名 + 对/错徽章。
- **差异标注**：
  - **必答要点清单**放在回答正文上方。每条要点前标 ✓ 或 ✗，来自保存的逐要点判分结果。右栏新满足的要点加绿色底色。左栏缺的要点用风险色写"缺少：……"。
  - **正文高亮**：只用保存的判分里引用的回答原句（`answer_quotes` 等字段）定位并高亮。右栏满足新要点的句子绿色底，左栏判为遗漏、矛盾的相关句子用风险色细下划线。
  - 保存数据里没有引用原句的，**不做正文高亮**，只保留要点清单，不靠关键词猜。
- **引用来源列表**：放在正文下方，保留可点开看原文。

### ④ 每栏下方"数据佐证"小表（两栏行一致、对齐）

| 行 | 内容 |
| --- | --- |
| 判定 | 对 / 错 |
| 必答要点 | 满足 x / y |
| 关键证据位置 | 未进入候选 / 被截掉（第 N 位） / 进入回答第 N 位 |
| 引用段落数 | |
| 本题回答耗时 | 秒 |
| 首字时间 | 秒 |
| 配置差异 | 只在右栏列出和 Baseline 不同的参数，用大白话，例如 候选条数 12→24、思考档位 最高→高、证据条数 4→6 |

- 每个数字都来自保存记录，缺失写"未知"。
- 数值更好的一方加粗；更差的一方**不隐藏、不改**，如实显示。
- 不写"绝对优势"之类的评价性文字，让数字说话。
