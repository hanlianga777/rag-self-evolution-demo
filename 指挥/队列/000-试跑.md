# 任务 000：自动值班试跑（不花钱，约 5 分钟）

## 目的
确认"值班脚本 → Codex 命令行版 → 提交"这条路在这台 Mac 上能走通。只做检查，不改任何项目代码。

## 要做的事
依次运行下面几项检查，把每一项的**原样结果**写进报告 `指挥/报告/000-试跑.md`：

1. 当前时间（`date`）、`codex --version`、当前目录（`pwd`）、`git log -1 --oneline`。
2. 能否联网：`curl -s -o /dev/null -w "%{http_code}" https://api.github.com`（正常应为 200）。
3. 能否在本机开端口（启动 demo 需要）：`python3 -c "import socket; s=socket.socket(); s.bind(('127.0.0.1',0)); print('ok', s.getsockname()[1])"`。
4. 能否写项目数据目录：在 `backend/data/` 下新建一个临时文件 `_试跑临时.txt`，确认存在后立刻删除。
5. 能否读 `.env`：只报告"文件存在 / 不存在"以及里面是否有 `DEEPSEEK` 开头的变量名。**不要把任何密钥的值写进报告。**
6. 能否改 `.git`（预期不能，只记录）：`touch .git/_试跑 && rm .git/_试跑 && echo 能 || echo 不能`。

## 报告格式
一个表格：检查项 / 结果 / 是否正常。最后一句写总结论：能不能开始正式值班。

## 完成后
按自动运行的规则：报告写好后，用普通的 `mv` 命令把本任务单移到 `指挥/历史任务/`。**不要运行 git add / commit / push**，保存和推送由值班脚本负责。
