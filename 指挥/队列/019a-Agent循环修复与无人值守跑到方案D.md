## 背景：为什么一直没有合格方案
1. **max 档已经没有速度余量。** Baseline 的 P99 是 42 秒，在 max 档上加任何一种检索增强，P99 都会超过 60 秒：HyDE 72 秒，查询改写 68 秒，TopK6 84 秒。只有降档的 R1-C 门槛全过（P99 25 秒）。

3. **最有希望的组合"high + HyDE"被规则误拦。** R1-A 的"max + HyDE"超时后，规则把凡是包含 HyDE 的改动都当成有害改动，"high + HyDE"从没跑过就被禁止了。

4. **循环一直跑，直到出现合格方案或预算用完。**

   - 新增一个"跳过某个未运行方案"的接口和页面按钮，被跳过的方案不占预算。
5. **无人值守授权（新功能，需要在页面上看得见）：**
   - 新增设置"无人值守授权"，记录授权人和授权时间。开启后，出现合格方案时，系统自动完成以下几步：

     2. 自动评估并生成方案 D；没有合适的互补来源时，记录"不生成 D，保留赢家"。
     3. 生成了 D 就自动跑 D 的完整 Sandbox。
     4. 出推荐结果后停在发布前。**绝不自动发布。**
   - 关闭时，行为和现在一样，等人工确认。
   - 用户已授权：本单最后一步开启这个设置。
