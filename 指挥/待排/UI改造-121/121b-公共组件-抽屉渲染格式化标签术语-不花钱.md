# 121b 公共组件：抽屉外壳、内容渲染、空值与数字格式化、状态标签、术语表（不花钱）

前置：121a 已通过总指挥验收。先读 `00-共同规范.md`。只改 `frontend/`。

## 要做的事

1. **抽屉外壳 `DrawerShell`**
   - 基于现有 `components/Dialog.tsx` 的 Radix 抽屉，保留焦点恢复、Esc 关闭、未保存修改确认。
   - 结构：
     - 固定头部：返回原页的面包屑、标题、身份行（编号 · 分类 · 状态标签）、单个关闭按钮；
     - 单层滚动正文；
     - 有业务操作时才出现的固定底栏。
   - 宽 800px。
   - 提供 `DrawerSection` 组件，统一处理区块标题、间距和「展开技术记录」折叠。
   - 全站现有抽屉都要换成这个外壳，只换壳，内容结构留给后续各页面单子。
2. **内容渲染组件 `RichContent`**
   - 在 `components/answerMarkup.tsx` 和 `StructuredAnswer.tsx` 的基础上收敛成一个统一入口。
   - 支持：段落、列表、粗体、`sup` / `sub`、Markdown 表格和 HTML 表格；内部引用标号保持可点击。
   - 解析不了的表格按原文显示，并加一行「原文为表格，可在知识库查看」。
   - 必须做安全清洗，去掉 script 和事件属性。
   - 证据原文目前走 `TruncatedText` 直接显示的路径，也要改成走它。
   - 单测要覆盖：`<sup>i</sup>`、被压平的「定期=；每12个月=x」样例（从 Golden 真实题里取）、普通 Markdown 表格。
3. **格式化 `presentation/format.ts`**
   - 实现共同规范第三节的空值和数字规则：`fmtCount`、`fmtPercent`、`fmtLatency`、`fmtCost`、`fmtTokens`、`fmtEmpty(kind)`。
   - `fmtCost` 对非零小额保留 2 位有效数字，例如 ¥0.0032。
   - 新增 `diffParams(before, after)`：只返回两边都有值、且值确实不同的参数。一边缺值的不算变化。
   - 单测覆盖「Temperature 0 → 未知」不出现。
4. **状态标签 `StatusBadge`**
   - 只保留共同规范第三节第 5 条的 4 类标签。
   - 「未晋升」用中性色，和「不合格」（失败色）区分开。
   - 删掉 `Primitives` 里多余的状态种类。
5. **术语表 `presentation/terms.ts`**
   - 以 `指挥/报告/UI-01.md` 的 55 条术语映射为基础，结合 `display.ts` 的 `parameterNames`，收敛成一份。
   - 参数中文名按共同规范四之二第 6 条的定稿表：Pipeline 页和技术详情带代码名，卡片只写中文名。
   - 删除 `max`、`Stepwise`、`Grounded`、`TableCheck` 的显示映射。
   - 全站参数名、状态名都从这里取。
