- **前端整体退回上一版**，即 032 改版之前的 `e37e7fa`。之后只按用户点名的问题逐条改，"我只需要在上一版基础上去进行优化"。

## 用户原话要点

- "这一版的前端 UI 优化修改完之后，相比上一版差的不是一星半点，差得特别多。"
- **做得最好、要往它们靠的**：自进化概览里的"优化成果"tab、Pipeline 配置、Bad Case 诊断 tab。其他 tab 和抽屉"做得真的很一般"。
- **Agent 工作台最失望**：
  1. 缺乏逻辑顺序：内容没有因果和前后顺序的关系。
  2. 长文本处理粗暴：没有用结构化的"1、2、3、4"总结性语言表达，只是把一大段文字收起来，同时在页面里留下大量空白。
  3. 卡片主题不明确：每张卡片想讲的主题不明显。
  4. Agent 能力不直观：第一眼看不出 Agent 的能力，像日志化的文字表达。
  5. 卡片以及段落字段并排的时候没有对齐。

## 用户明确讨厌的样式（附图）

1. **收起 / 展开按钮**，例如"▶ 未预测到的新问题""▶ 展开 Agent 分析""▶ 技术详情""▼ Sandbox 对比表"。"有必要的就直接展示出来，没有必要的不要设置这种按钮。"
2. **一排参数小标签**，例如"相对 Baseline 的改动：[思考档位 Max → High] [回答策略 有据生成 → 分级回答]"。"很 low"。
3. **多个带 i 的标签并排**，例如四个原则标签。"很奇怪"。
4. **发布页最底部**："版本历史"被截住看不到。
5. **列表**：像 Golden 测试集这种，所有列表的每一列都要不用滚轮、在首屏就能看到全部字段，安排紧凑一点。
6. **运行进度小卡片**：Agent 工作台右下角的深色悬浮进度卡（例如"Candidate C 正在运行 37/50 题""A/B/C · Sandbox 自动循环"）很丑。要优化，风格跟现有页面接近，即浅色卡片。
