## 第二步：清理空间（先打包，再删除）
1. **盘点**：列出以下范围里所有大于 10MB 的文件和文件夹，以及大小：
   - 项目文件夹（包括 `.git`）；
   - Codex 在项目外建过的临时工作区和备份（例如 `/private/tmp/rag-task001-snapshot`，以及任务 001、002 里另建的工作区）；
   - 本地分支 `codex/本地全量备份-001` 占用的空间。
2. **必须保留、不动**：
   - 正式数据库 `backend/data/demo.db`；
   - 当前知识库在用的原文件和索引；
   - Git 跟踪的所有文件；
   - 本地分支 `本地旧main-备份`。
3. **其余全部归入"待删除"**：数据库副本和备份、测试/审计用数据库副本、`output/`、截图、日志、压缩包、旧的运行产物、Codex 的临时工作区、`codex/本地全量备份-001` 分支及其分卷压缩包等。
4. **先打包**：把"待删除"里的所有内容压缩成一个总备份包，放在项目外的 `~/RAG归档/`（用最高压缩率）。打包后逐个核对文件数和 Hash，确保能完整还原。
