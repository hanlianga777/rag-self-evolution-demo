## 二、GPT 独立方案摘要（全文见 ChatGPT「Agent阶段风险审查」11-25 回复）

1. 定位：专业、克制的企业级 AI 评测工作台。原则是"首屏讲结论，第二层讲过程，抽屉讲证据，原始记录按需展开"。
2. 信息架构：保留 8 页，导航按阶段分组（知识与评测准备 / 评测与优化 / 发布与运营）。倾向浅色导航，交由用户定。
3. 设计体系：
   - 版式与尺寸：12 列网格；导航 216px；抽屉 800px；卡片圆角 10px；表格行高 48px。
   - 字号：标题 24、KPI 32–40、正文 14、辅助 12–13。
   - 颜色：背景 #F6F7F9、主色 #315E9E；状态色只表达语义，「未晋升」用中性色，不用失败色。
4. 组件规范：KPI 卡只分三层；标签只用于四类（结果、资格、工作流状态、决策状态）；证据引用块用短文档名加页码，技术字段默认折叠；空值规则区分 0、—、不适用、未运行、该版本未记录，禁止把「0 → 未知」当成变化；统一内容渲染器，补上 sup/sub 和表格。
5. 三个抽屉模板：
   - 题目抽屉：题目 → 参考答案 / 预期行为 → 核心证据 → 辅助引用 → 质检 → 技术记录。
   - Bad Case 抽屉：问题 → 诊断结论 → 回答与参考答案对比 → 未满足要点 → 证据链 → 优化方向 → 复核与技术记录。
   - Candidate 抽屉：摘要 → 参数变化 → 优化假设 → 评测结果 → 预测与实际 → 回归 → 复盘 → 技术记录。
6. 实施：先抽设计 token 和公共组件，补丁 CSS 先迁移再删；拆 6 张单（UI-01 基础 / 02 公共组件 / 03 概览·知识库·黄金集·Pipeline / 04 Baseline / 05 Agent / 06 发布·问答·全站回归）。截图验收覆盖 1440×900 和 1280×800，以及各种状态分支。
7. 不做：不改业务规则；不重跑；不展示未实现的护栏；不加动画框架；不隐藏失败方案；不硬编码成绩。
