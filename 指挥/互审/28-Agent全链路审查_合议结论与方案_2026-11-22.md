## 一、Claude 认错和接受的更正

1. **"子块向量缺少标题"是错判，撤回。** 正式索引走的是 `knowledge_pipeline.py:179 child_embedding_text`，已经把文档名和 section_path（具体到四级标题）拼在正文前面；`build_index.py` 是旧路径。知识库不需要为这个问题重建。改为抽查 30 个子块实际送进向量模型的文本，确认上下文够不够。
2. **规则口径没统一（P0）。** 规则总表六.5 已改为 `2026-11-20b`，但 `rules.py` 里的 `RULES_VERSION` 和规则总表末尾的机器可读 JSON 还停在 `2026-11-20`，`max_changed_parameters` 仍是 2。要统一，历史版本保留。
3. **105b 有两处冲突（P0）：**
   - D 改 3 个参数：用户说过"再加 1 个参数"，但代码上限是 2；
   - Gate 2"预授权代确认"：规则总表八.2 要求等用户下令。
   
   两项都请用户亲自定。105b 继续暂停。
4. **"预测命中率 9/9"要改个说法。** 同一道题会被重复预测，而且检索预演用到了 M1 的标准证据。准确的表述是"已知题上的预测命中，检索方向 9/9 次、生成方向 0/3 次；同一题可能重复计入"。
5. **25 号审计中的 3 道"隐藏错题"要降级为"待确认候选"。**
   - Baseline Q24：手册说 245 ml 只是参考量，要以油位为准，回答说"没有规定具体加多少"可能不算错；
   - C 的 Q22：要按条件范围核对；
   - A 的 Q17：属于明确的内部矛盾。
6. **110 号未见题卷要修订。**
   - 只覆盖 7 个库内主题，加 2 道库外题，不是 9 个主题；
   - H04（150 Nm 与 Q48 重合）、H07（与 Q49 重合）、H09（与 Q03 重合）三题和 M1 的考查事实重叠，要替换；
   - 修订后再做探针和 QC，只在方案选定后运行一次。
7. **不能在历史实验上补写当时没有生成的 Agent 推理。** 只能从保存的事实重建展示，并标注"事后重建"。
