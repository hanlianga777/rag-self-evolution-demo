## B. 章节识别修复（规则总表一.2、一.3）

1. **参考补丁**：`指挥/互审/附件-章节识别修复参考补丁.patch`。思路是：手册中编号标题（如 `5.4.1 更换底座`）足够多时，按编号标题分章；与当前章同名的续页标题不另起一章。请按这个思路实现，可以改进，但必须满足下面的验收标准。`heading_hierarchy` 版本号改为 `manual-chapters-v2-numbered`。

2. **父块不跨章，语义边界优先于父块最小长度**（GPT 反审 11-20）：
   - 任何一个父块里，不能出现两个不同的编号标题。
   - 1400 token 是上限，不是必须填满的目标。章节太长，就在章内按自然段、表格、步骤拆开。
   - 真实小节很短时，**允许出现低于 400 token 的短父块**，不要为了凑长度去合并另一个独立小节。短父块在报告里列出数量和原因。
   - "单子块父块 ≤15%"一项若与语义边界冲突，以语义边界为准，在报告里如实列出。
   - 标题文字必须留在章节路径里，同时出现在该章第一个子块的正文开头，保证标题可以被检索到。
3. **编号标题识别的护栏**（GPT 反审 11-20），以下几种情况**不能**触发分章：
   - 目录页里的编号条目（目录行通常带页码、点线，或连续多行都是编号）；
   - 正文里引用的章节号（例如"请参阅 5.4.1"）；
   - 表格、图注里的编号（例如"表 3""xx2300001370"）。
   - 同名标题只有在**连续出现、而且章节身份相同**时才视为续页、合并；不相邻的同名标题按两个章节处理。

4. **清理正文残留**（`denoise_version` 加一版）：
   - 整行只有图片编号的（如 `xx1400000590`），删除。
   - 简单的 LaTeX 转成纯文本：
     - `$580 \text{ ml}^{\text{i}}$` → `580 ml`（脚注上标去掉）；
     - `$DTC^{ij}$` → `DTC`；
     - `$H_2O_2$` → `H2O2`；
     - `$-25^{\circ}C$` → `-25°C`。
   - 无法安全转换的公式保留原样，在报告里列出数量和 3 个例子。
   - 标题行不能粘在上一个子块的末尾。

5. **单元测试**：覆盖下面几种情况。
   - 错误的一级标题（"目录""从下臂上分离电缆束"）不会成为章；
   - 编号标题正确分章；
   - 同名续页标题不另起章；
   - 父块不跨编号标题；
   - 目录行、正文引用的章节号、图表编号都不会触发分章；
   - 短小节形成短父块，而不是被并进相邻小节；
   - 图片编号行被删除；
   - LaTeX 转换正确。
