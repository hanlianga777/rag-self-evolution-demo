## 本轮总背景（027a–027h 共用，请每张都先读这一段）

**目的**：用户 11-12 逐页看完 demo，提了 48 条意见。**大前提**：demo 上的一切都是为了面试时以 AI 解决方案工程师的身份讲解，同时也可能拿给客户看。所以：

- **页面文字**：自然、完整、有温度的长句；不要 AI 味的短句、生硬翻译或"→"堆出来的短语。
- **要删的文字**：一眼能看懂的东西不要再配小字说明；废话、日志腔的备注、内部状态词一律删。
- **保留的风格**：苹果灰 + 蓝的配色、蓝色饱和度和蓝框；不重要的字浅灰、缩小；线性 SVG 图标（`frontend/src/ui/icons.tsx`，不用 emoji）。
- **分工**：本轮页面级 UI 由 Codex 按现有设计变量（`ui.css`、`extra.css` 里的 token 和类）实现；总指挥已写好的新组件在 `frontend/src/ui/architecture/` 和 `frontend/src/ui/knowledge/KnowledgeFlow.tsx`，样板见 `/ui-gallery.html` 顶部。

**每张任务单都适用的硬性约束**：

- 不调用模型，实时问答不发送；
- 不改评测数据、Golden、门槛、Judge 原文和 Agent 推理原文，只改展示；
- 不发布，不回滚，不新增问答或反馈记录；
- 不要运行 git 写命令；不改 `指挥/当前任务.md`；demo 保持运行；
- 前端全量、后端全量保持全绿，后端 21 处既有跳过不变。

## 本单内容：全站通用规则（后面几张都依赖它，先做）

### 1. 页签样式统一（用户第 6 条）
- 全站只保留一种页签样式：一级页面现在用的 `.tabs`（文字 + 选中项下方一条直线）。
- 抽屉里、卡片里所有"带弧线 / 胶囊底 / 分段控件"样式的页签都改成这一种。已知的有"查看分块示例"抽屉，其他地方全局搜一遍。
- **例外**：轮次切换按钮（Round 1 / 2 / 3）属于筛选按钮，不是页签，保留按钮组样式，但全站按钮组只用一种样式。

### 2. 悬停提示统一（用户第 9 条）
- **唯一样式**：全站悬停提示统一为**黑底白字、圆角**的浮层（现有 `.ui-float.dark` 的样式），白底浮层全部改掉。
- **只在截断时出现**：文字没有被截断、第一眼就能看完整时，悬停**不出现**提示，也不出现可点击的光标。例如知识库文档名能完整显示时，就不该有提示。
- **截断了必须有提示**：反过来，凡是被截断（省略号、行数限制）的文字，悬停**必须**出现提示并显示全文。已知漏掉的有：Golden 列表里 QC 审核描述、"参数说明"抽屉里的单元格。
- 统一用 `ClampText` 一类的组件做截断检测，全站搜一遍。

### 3. 蓝色按钮统一（用户第 14 条）
- **主按钮**：全站只保留一种蓝色按钮，就是概览大卡上"去问答验证"那种：实心蓝底 `--ui-accent`、白字、10px 圆角、可带白色图标。
- **浅蓝底蓝字按钮**（`.ui-btn-tint` 一类，例如"参数说明""进入 Agent 处理""新建对话"）：不再使用，按重要性分两种处理：
  - 这一块区域的唯一主操作 → 实心蓝；
  - 其他 → 白底细边的次要按钮，和知识库"新增文档"一样。
- **数量**：同一个视口里实心蓝按钮最多 1 个。
- **文字链接**：像日志一样的"文字链接式"操作入口（例如"查看 D 完整报告""查看目标 3 题"），统一改为白底次要按钮，带图标的更好；表格行内可以用小号次要按钮。具体位置在后面几张单里，本单先把样式类准备好、写进 `extra.css`。

### 4. 抽屉统一（用户第 18、32 条）
- **背景**：所有抽屉背景统一为白色，不要灰底。抽屉里的分区用浅灰细边小卡（现有抽屉分区卡样式），分区卡本身是白底。
- **滚动**：抽屉里的"参数差异"等区块取消内部滚动条，内容全部展开，只保留抽屉整体滚动。

### 5. 禁用说法（用户第 18 条）
- 全站页面文字里不能出现："单遍判错"，以及之前定下的"导入、内部、试跑、复跑、随机、不稳定、MEDIUM、FULL、内部编号、原始时间戳"。
- 全局搜源码和接口返回的展示字段（只改展示映射，不改保存数据），报告里列出替换清单。

### 6. 命名统一（用户第 36、43 条）
- **Candidate 编号**：凡是同一张表、同一个对比里会出现两个以上轮次的 Candidate，一律写成 R1-A、R2-C、R3-C 这种格式；只出现在单一轮次上下文里时，仍写 Candidate A。Candidate D 写 Candidate D。
- **Before / After**："优化前 / 优化后"在问答验证和概览里统一改成 Before / After，和页签名一致。

### 7. 金额统一为人民币（用户第 22、34 条）
- 全站所有费用一律以人民币显示，格式"¥ 0.83"。
- 如果保存的是美元，按一个写在代码常量里的固定汇率换算（汇率写在报告里）；如果能从 token 用量按 DeepSeek 官方人民币价格计算，优先这样算。
- 页面上不出现"USD""$"。

### 8. 首屏规则（用户第 48 条，后面每张单验收时都要检查）
内容不多的页面和页签，在 1440×900 下切进去，卡片应基本在一屏内放下，不需要滚动，也不要"只露出一点点"。下面这些尽量做到一屏：
- 项目概览；
- Pipeline 配置；
- Golden 当前测试集：表格本身可以内部滚动，外层不滚。

做不到的保留整页滚动。手段可以是收窄卡片、收紧间距、减少说明文字。本单先写一个 Playwright 检查脚本，列出每页每个页签的"内容高度 / 视口高度"，放在 `output/task027a/fit-check.json`，后面几张单复用。
