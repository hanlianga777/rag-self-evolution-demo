## 2. 八个页面标题下的说明语（用户第 2 条）
把每个一级页面标题下那行浅灰小字（`.page-purpose`）换成下面的句子，原样使用。如果 1440 宽下一行放不下，可以缩到 12px，不要换成短句：

| 页面 | 说明语 |
| --- | --- |
| 概览 | 用一组数字和一条闭环，说明这套系统让智能客服变好了多少，又是怎样一步步做到的。 |
| 知识库 | 把设备说明书解析成可以检索的知识片段，让每一句回答都能追溯到说明书的原页。 |
| Pipeline 配置 | 这里放着固定不变的技术底座和 Agent 可以调整的 12 项参数，也就划定了自动优化的边界。 |
| Golden Dataset | 黄金测试集是评测用的标准考卷，50 道题冻结之后，每一轮优化都用它来打分，前后结果才有可比性。 |
| Baseline | 用黄金测试集给当前版本做一次完整体检，看清门槛是否达标、哪些题还答不好、问题出在哪一层。 |
| Agent 工作台 | Agent 根据 Bad Case 的成因提出不同方向的 Candidate，在 Sandbox 里用同一套考卷比较，找出既修好问题又不弄坏其他题的方案。 |
| 发布 | 程序只负责判断能不能发布，是否上线由人来批准，每次发布都会保存快照，随时可以回滚。 |
| 问答验证 | 用同一道题优化前后的真实回答做对照，也可以直接向线上版本提问，查看回答和它引用的原文。 |
