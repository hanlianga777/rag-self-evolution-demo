## 要改的

### 1. 复盘和 D 理由里的"相关题目/相关题目"占位符看不懂
进化路线的"Agent 本轮复盘"和"Agent 判断不做 D"理由里，题号被替换成了"相关题目"。结果出现"能修相关题目/相关题目并附带修相关题目"这样读不通的句子。

改为：
- **题号**显示简短题号，例如 Q24，**悬停显示题目原文**。题号是讲故事要用的标签，不算"编号外露"；实验编号、评测编号、文档片段编号、哈希仍然不能露。
- **文档片段编号**（如 DOC-001-C-00096）改成"相关说明段落"。
- **英文参数名和指标名**统一转成页面已有的中文名，例如：
  - `top_k=6` → 回答证据条数 6
  - `safe_rejection` → 安全拒答率
  - `rerank=query_only` → 重排方式：只按问题
  - `hybrid_alpha` → 向量检索权重
  - `hyde` → 假设答案检索
- 只改**显示**，不改保存的原文。

### 2. 进度条卡片要反映 D 的真实结论
- "方案 A/B/C/D"卡片现在写"D 待组合判断"。按 D 的实际状态改，例如"Agent 判断不做 D""D 已生成""D 试跑中"。
- "最终推荐"卡片现在写"候选方案 C"，改为"第 3 轮方案 C"，和页面其他地方一致。

### 3. 最终推荐理由要和 D 结论一致
- 现在显示的是"D未同时满足发布资格与优于赢家；保留具有发布资格的赢家"。这句话对"合法不生成"的情况不对：D 根本没生成，谈不上"不如赢家"。
- 前端按 `d_outcome` 选择文字：
  - **declined**："Agent 判断不做 D：已验证能修剩余错题的改动会伤到已答对的题和安全拒答，没有可靠的改法，因此保留第 3 轮方案 C。"可以从保存的理由里摘一句，但不要编。
  - **D 已评测但没胜过赢家**：保留现在的意思，用大白话写。
  - **D 胜出**："D 胜过赢家，推荐 D"。
- 进化路线的"最终推荐"节点和"最终推荐"页签都要改。

### 4. 删掉重复入口
- 进化路线上方的"历史实验 · N 轮"按钮，和进化路线本身重复，从主画面去掉。
- 历史实验抽屉保留在右上角"更多"菜单里。

### 5. 小的排版问题
- **发布页**："确认发布"按钮和"查看评测报告"链接贴在一起，加正常间距。
- **进化路线**：方案卡片在第一眼就要看到"修好"和"弄坏"两行。现在第 3 轮方案 C 的"弄坏：无"被截掉了，要让这两行在卡片首屏可见，其余内容在卡片内部滚动。
