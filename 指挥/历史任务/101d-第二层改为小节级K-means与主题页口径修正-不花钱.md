## 1. 第二层：对"编号小节"做 K-means，不再对单个子块做

1. **聚类单位**：每个编号小节作为一个单位。
   - 维修、维护取第三级编号（如 5.6.2、4.6.1）；其余主题取能取到的最深编号层级。
   - 每个单位的向量 = 该小节全部去重子块向量的平均。
2. **聚类范围**：只对正向配额 ≥2 的业务主题做。k = 该主题的配额，且 ≤ 小节数；seed 42，n_init 10。
   - **不要沿用子块级"小于 3 个合并"的规则**：小节级每组最少 1 个小节即可。
   - 如果实际得到的组数 < k（例如向量重复），在报告里写明原因，**不能用重复命名凑数**。
3. **组的业务名称**（页面上以业务名称为主，编号小节放在展开明细里）：
   - 按组内小节标题里的部件或活动关键词归族。词典：
     - 电缆、线束、连接器、SMB、制动闸释放 → 电缆线束与连接器
     - 电机 → 电机更换
     - 齿轮箱 → 齿轮箱维修
     - 下臂、上臂、外壳、延长器、管轴、倾斜单元、摇摆部、底座、密封 → 机械结构与密封件
     - 机械限位、限位装置 → 机械限位
     - 电池 → 电池
     - 油 → 润滑与换油
     - 清洁 → 清洁
     - 检查、维护计划 → 检查与维护计划
     - 吊、搬运、运输、提升 → 搬运与吊装
     - 安装、固定、基座 → 安装固定
     - 连接、布线 → 电气连接
     - 校准、标定 → 校准方法与步骤
     - 螺钉、拧紧 → 螺钉与拧紧转矩
     - 润滑、油类型 → 润滑剂
     - 备件 → 备件
     - 停用、废弃 → 停用与废弃
   - **业务同质性** = 组内属于占比最高那一族的小节数 ÷ 组内小节数。
     - ≥60%：用该族名；
     - 两族合计 ≥80%：写"A 与 B"；
     - 都不满足：写"混合：A、B 等"，并在报告中标出。**不准把某一个小节的名字当整组的名字。**
4. **配额**：主题配额按各组去重片段数，用最大余数法分到组。
5. **导出**：
   - `101d-章内分组.csv`：业务主题、组、业务名称、同质性、成员小节（编号 + 标题，按编号排序）、片段数、配额；
   - `101d-小节归属.csv`：小节编号、标题、业务主题、组。
