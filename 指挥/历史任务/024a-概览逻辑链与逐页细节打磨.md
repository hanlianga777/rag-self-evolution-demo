## 1. 概览（讲解起点，最重要）
1. **加逻辑链**：标题下面、44 → 48 大卡上面，加 `ValueChain`。三段文字如下：
   - **问题**："RAG 上线后答错难发现，调参靠试，修好一题又弄坏另一题"，说明："不知道该改哪里，也不敢上线"；
   - **方法**："冻结考卷量化 → Agent 在白名单内调参 → 人工批准发布"，说明："每一步可量化、可归因、可回滚"；
   - **结果**：标题和说明里的数字全部从现有数据算，**不写死**。格式参照"答对 44 → 48，新增 Bad Case 0，P50 快 51%"和"11 项 Hard Gate 全过，安全拒答 95% → 100%"。
2. **状态行并入大卡**：单独一行的"已发布 Candidate D ＋ 去问答验证"并入 44 → 48 大卡右下角，作为一行小字状态加按钮，省出一整行。
3. **"优化过程"讲解区**：Round 1、Round 2 现在写的是"本轮没有合格 Candidate：3 个新增了 Bad Case……"这种计数，改为显示和进化路线**同一套"本轮经验"**（023 改好的完整句），保证两页说法一致。Round 3、Candidate D 两行保持现状。
4. **流程条文字不换行**：例如"已评测 · 11 / 11 项 Hard Gate 通过"会折成两行。缩成"11/11 Hard Gate 通过"一类短句，6 个节点都保持一行。
5. **验收**：1440×900 下，逻辑链、44 → 48 大卡、流程条、讲解区在首屏到第一屏半内看完。
