## 1. 概览 →「项目概览」页签
- 原来的五张指标卡、"从知识到线上改善"流程条、"当前下一步"卡、线上版本说明行，换成一个 `OverviewSummary`。
- **props 从 `OverviewPage.tsx` 现有的计算结果取**，不新写数据逻辑：
  - `correct`、`p99`、`p50`、`safeRefusal`：Baseline 对最终推荐，沿用 `qualityValue` 的数据来源；
  - `fixedCount`：最终推荐修好的原 Bad Case 数；
  - `newBadCount`：新增 Bad Case 数；
  - `gates`：最终推荐的 Hard Gate 通过数；
  - `budget`：`evaluation_budget`。
- **`status` 必须由线上版本数据算出**，不能写死：
  - 推荐未发布时：`pending_release` +"Candidate D 推荐待发布"，当前线上为"初始配置"；
  - 已发布时：`released` +"Candidate D 已发布"，当前线上为"Candidate D"。
  - `primaryAction`：未发布时是"去发布"，跳转发布页；已发布时是"去问答验证"。
- **`flow`**：6 步。每步的 `fact` 用现有 `stages` 的真实状态，改成短句；`tips` 写 2–3 条补充事实，不写主画面已有的数字。点击跳到对应页。
- **原"当前下一步"的其他分支**（例如需要重建 Golden、Baseline 失败），继续由 `primaryAction` 的文字和跳转承接，**逻辑分支一个都不能丢**。

## 2. Agent 工作台：顶部、页签、进化路线

### 2.1 顶部
原来六张"✓ 已完成"绿卡，加上下方那一行进度，换成 `AgentStats`：轮次、Candidate 数、评测预算、当前状态。

- **状态的取值**：
  - 推荐未发布：`recommended` +"推荐 Candidate D，待人工发布"；
  - 已发布：`released`；
  - 评测中：`running`。
- 原来卡片上的阶段信息如果有独有用途，例如运行中显示进度，在 `AgentStats` 的状态文字里体现。

### 2.2 页签改为 5 个
进化路线（默认）| A/B/C/D | Sandbox | Regression Check | 最终推荐。

- **"问题诊断"页签取消，但先迁移它独有的功能**：
  - 6 题完整诊断列表在 Baseline →「Bad Case 诊断」里已经有。进化路线起点行提供"查看 Bad Case 诊断"，跳过去并直接打开该页签。
  - "优化优先级"表里"检索层 5 · 严重 · 修复思路"的信息，在进化路线起点行用分层计数体现。
  - 如果问题诊断页签里有**别处没有的按钮或操作**，列出来，迁移到合适位置后再删除，**一个都不能丢**。
- 深链和状态恢复（URL、记住上次页签）照常可用。旧的"问题诊断"深链改为打开 Baseline 的 Bad Case 诊断。

### 2.3 进化路线页签
- 用 `EvolutionTimeline`：
  - `model` 由 `buildEvolutionModel(experiment, baselineConfig, metric => gateNames[metric] ?? metric, schemeName)` 得到；
  - `baseline.badCases` 来自现有的 Bad Case 数据，`layer` 用现有分类名（检索层、生成层……）；
  - `questionText` 用现有 `questionText` 函数。
- **`baselineConfig`** 是 Baseline 运行时的 Pipeline 参数。从 Baseline 评测记录或 Pipeline 接口里找到正确字段，**不写死**。核对页面显示 Candidate K 12、Top-K 4、Thinking Max、向量权重 0.5、Multi-Query 关闭、回答策略 有据生成，和样板一致。
- **`onOpen`** 打开现有的方案详情抽屉，也就是原来点方案卡打开的那个。
- **children** 放现有的 Candidate D 区块（`DStory`）：预测 vs 实际、受保护题、门槛逐项、Winner 与 D 并列、没修好的原因、结论句。**内容不删**，只把它的外层卡片样式改成和新卡片一致：
  - 白底，阴影，圆角 14，Winner 深色描边；
  - 题号用 `QuestionBadge`；
  - 参数变化用 `ParamChip`，"Top-K 4 → 6"标"唯一新增"。
- **删除**进化路线底部那张重复的完整"最终推荐"表，只留一个"查看最终推荐"按钮。按 GPT 方案"唯一主讲位置"原则，完整推荐只在「最终推荐」页签出现。
- **文字处理**：`storyText` 里把英文译回中文的替换（Winner → 赢家、Thinking → 思考、high → 高 等）要和 021r 的英文规则一致，**不能再译回中文**。
