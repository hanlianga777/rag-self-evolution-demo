# 032m：把上一版前端并排开在 5175，供逐页对比（只读）

**授权**：用户已授权，不需要停下来等确认。

## 背景

用户 11-15 早上看完 032 系列改版后，认为整体比上一版差很多，要求"在上一版基础上去优化"。

这里的"上一版"指 032 系列开始前的前端，即提交 `e37e7fa`（031g 完成时）里的 `frontend/`。

总指挥需要把两版逐页对比后，再决定每一页是保留新版、退回旧版，还是在旧版上细修。所以本单**只开一个只读的旧版对照站，不改现有代码**。

## 要做的事

1. **取出旧版代码**：用 `git worktree add` 或 `git archive e37e7fa frontend` 把旧版 `frontend/` 放到仓库外的独立目录，例如 `~/RAG归档/前端对照-e37e7fa/`，复用或单独安装依赖。
   - 不要动当前工作区；
   - 不要提交任何构建产物。
2. **只读代理**：在 `127.0.0.1:8011` 起一个很小的代理，转发到 8010。
   - 只放行 GET / HEAD / OPTIONS，其余方法一律返回 405，并记录到本机日志；
   - 旧版界面里有"重新评测""运行"等按钮，误点会花钱，这个代理就是为了挡住它们。
3. 用 `VITE_API_BASE_URL=http://127.0.0.1:8011` 构建旧版，再用 `vite preview --host 127.0.0.1 --port 5175 --strictPort` 提供。
4. 写一个启动脚本 `scripts/start_compare_old_ui.sh`（可以提交），一条命令同时拉起代理和 5175，再一条命令能关掉。在 README 里加两行说明。
5. **两版截图，各页对齐**：1440×900 下，旧版 5175 和新版 5174 各截一套，按页面一一对应，保存到本机 `output/task032m/对比/`，命名为 `<页面>-<页签>-old.png` / `-new.png`。范围：
   - 每个一级页面的每个页签；
   - 每个页面最主要的一个抽屉；
   - Agent 工作台：Round 1、Round 3、Candidate D、回归与推荐；
   - 发布页拉到最底部；
   - Golden 列表右侧是否有被截掉的列。
6. 报告里列出每个对照页的截图文件名，以及两版之间肉眼可见的主要差异，每页 3 条以内，不下结论。

## 约束

- 不调用任何模型，不花钱，不写数据库。旧版站点上任何写请求都必须被代理拦下：用一条 POST 测试请求证明返回 405。
- 5174 和 8010 保持不动。
- 报告写到 `指挥/报告/032m.md`，截图只留本机。完成后 5175 和 8011 **保持运行**，供用户和总指挥对比。
