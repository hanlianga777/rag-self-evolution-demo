### Agent 工作台

1. 实验进度不再折叠，六个页签顶部始终显示。六张卡分别跳到诊断、优化 Agent、候选方案、Sandbox、回归检查、推荐；人工确认和组合 D 保留在对应内容中。
2. A/B/C 三列等宽、等高，标题与状态固定，正文用一个滚动区域。1440×900 下卡高 560px，1280×800 下卡高 470px。内容顺序为：方向、核心思路、参数变化、针对的题、预期效果、风险、结果。
3. 卡片只保留一份参数表，列为“参数 / 原值 / 新值”；删掉卡内重复的策略、调整项与风险区块。结果区域保留修好/弄坏的题、门槛、回归、P50 / P99 与资格；未完整评测时不预判成绩。
4. 方向优先读取保存的 `reasoning.direction`，实际 A/B/C 标签分别为“检索召回增强”“排序与过滤”“效率（降档 + 检索补偿）”；没有从参数变化反推方向。
5. Sandbox 增加运行状态行，运行中的方案显示“运行中 X/50”，暂停时显示“高峰时段暂停 X/50”；指标尚未完成时不冒充正式结果。断点与费用内容收进技术详情，空卡不再出现在主画面。
6. 优化 Agent 页按“读到了什么事实 → 提出了什么假设 → 得出了哪些方案”排成卡片，保留问题证据、假设关联、方案详情、逐题覆盖和缺口。
7. 主按钮与“更多”放在标题行右侧。既有身份阻断、预算、续跑、人工确认、D 和发布资格行为保留。

来源：`pages/EvolutionPage.tsx`、`pages/evaluation-workspaces.css`、相关 Agent 测试和 `directions.json`。

- “一种绿色”是沿用一组成功色变量，包含浅底、边框、文字三种用途，不另起绿色色系。
