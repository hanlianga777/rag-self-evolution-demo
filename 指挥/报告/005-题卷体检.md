# 任务005：题卷体检和修订稿

本轮只形成审稿材料，没有修改数据库、冻结新题卷或调用付费接口。原50题按顶层必答计126条，修订为106条；新稿的C1、C2、C4、C5、C6、C8在适用题上均通过。C3还有7题词法初筛项，逐条理由见下；C7只给检索候选，Q36局部约30秒条款需要总指挥判断。

来源与版本：先拉取main到 `8da8275`，按 `指挥/当前任务.md` 任务005执行。原题卷来自 `003-数据/题卷50.csv`（任务指定冻结版本GD-20261031071527）；来源文字为当前 `backend/data/index/` 的chunks/parents/full_text、documents及逐页blocks。未用当前数据库补写原CSV字段，未访问外部资料。全部页码为PDF物理页，1起算。

## 体检程序和复跑命令

程序：`backend/scripts/task005_golden_check.py`；只用Python标准库，输入同格式CSV，支持 `--index-dir` 更换本地解析索引目录。无数据库、网络或模型调用。

```bash
python3 backend/scripts/task005_golden_check.py 指挥/报告/003-数据/题卷50.csv --output 指挥/报告/005-数据/体检_原题卷.csv
python3 backend/scripts/task005_golden_check.py 指挥/报告/005-数据/修订稿50.csv --output 指挥/报告/005-数据/体检_修订稿.csv
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=backend:backend/tests python3 -m unittest test_task005_golden_check -q
```

证据按NFKC、大小写、空白和Unicode标点归一化后连续查找；没有按切块编号判断相等。C1查按页原文流，C2单独查单子块；仅母块命中会明确报跨子块风险。C8用原文字面实际命中的页集合，不拿子块page_start/page_end当真实位置。

C3提取数字/单位、按钮名、部件主题和动作词作字面初筛；C4给出每段与要点的全文命中或具体关键词/连续片段部分支撑；纯年份等数字重合不算支撑，短句中的“未说明”“不把…扩大为”等同类限定语也由C6检查。不靠“设备/清洁”等泛词放行，也不要求一段证据独自支撑一个复合要点的全部文字。C4通过表示词法关联，不能证明否定、条件、产品范围等完整语义。修订内容另由Codex逐题对照原文，不冒称人工批准。

C5优先2–3条；Q02/Q05/Q11/Q14/Q19只问一个按钮、防护用品、代码是否重复、紧急停机动作或登录动作，保留1条。C6检查必答及原条件行中的限定语和超过40个归一化字符的长句；新加分、禁止、等价列不混入必答计数。修订稿另外逐条检查了原始短句长度，106条最长28字，不超过30字。

C7对当前368个子块做本地BM25，使用中文二元词和英文/数字词，去掉客户、说明书、资料等泛词及来源中已知型号标识，对业务动作词加权3倍。候选位置再按原文定位真实页，输出3段全文、匹配词和分数。原8题、新7题的候选分数都大于0；“通过”只表示完成检索，不是有答案/无答案结论。前三名不含答案不等于手册没有答案，Q36的30秒段就是人工从相关流程继续核对找到的。
