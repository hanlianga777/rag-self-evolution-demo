# 032b 执行报告

本单实现了统一的模型回答组件，以及逐题抽屉中按必答要点对齐的判分标签和检索表。只调整展示，不重新生成回答、不重新判分、不改保存的评测数据。

## 起点与理解

- 已先读根目录 `AGENTS.md`、`指挥/README.md`、032b 任务单、第三轮方案/文案、前端设计规范和用户复盘意见。
- 开始时 `git status --short` 为空，最新提交 `f031702` 是本单开始记录；没有发现本单旧报告或半成品。从现有回答组件继续改造，没有重跑历史任务或付费题目。
- **我是这样理解的**：“统一回答”是统一呈现同一份模型原文，不替模型补写结论或操作步骤。只有明确标记为“结论”的段落才前置；未标记的原句保持原来的顺序。新旧回答都能展开“查看原文”核对完整原始输出。
- **我是这样理解的**：新 Prompt 的“注意：”用于安全警告，必须留在正文。仅将明确的“证据边界”“未确认条件”“说明”“依据”，以及“注意：以上信息……”一类元说明折叠；不把所有“注意”都藏起来。
- **我是这样理解的**：负向题也保留每一条必答要点和对应检索行；没有可绑定的标准来源时，各格写“—”，不统一省掉整张表。未知判分用灰色，不冒充没答到。
- **我是这样理解的**：回答的引用列表只列模型实际引用的来源，不把全部检索上下文都说成模型已引用。文字引用、原文片段、原始回答均保留可查。
