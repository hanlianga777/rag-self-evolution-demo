## 引用替换及原句高亮

实现位置：`frontend/src/components/ComparisonAnswer.tsx`；Markdown 解析复用 `CaseAnswer.tsx` 的 `answerMarkup`，没有引入依赖。

1. **先替换引用，再解析 Markdown。** 支持书名号文件来源、括号中的章节/页码、来源在前的写法、同上/同文件/同手册/同文档/同说明，以及同一括号里的分号分隔多来源。编号按回答中的出现顺序生成，同文件同页复用编号，“同上”沿用此前来源。文件名匹配使用保存文件名及常见名称写法归一，页码保持回答明确写出的页码，不改成“最接近”的页码。
2. 引用替换成占位符后，文件名下划线不会进入 Markdown 斜体解析。再将占位符显示为上标圆标，来源栏去 `.pdf`、下划线换空格。段落、标题、加粗、有序/无序及嵌套列表均实际渲染。
3. 同一引用中先引用整机手册、后引用遥控手册时，按分号逐段处理，避免把前一页错误归给后一文件。文件名后的正文说明不能被当成引用删掉；已加入“文件后接加粗页码说明”的回归测试。
4. 不把《使用手册》这类普通泛指自动当成有来源的引用。不在保存 Trace 中的页码写“原文未保存”，不拿别页原文冒充。
5. `**证据边界：**`、`**未确认条件**：` 开头的段落保留全部正文，用浅灰说明框展示。
6. **高亮仅由 `answer_quotes` 定位。** 引文与正文都去引用片段、Markdown 展示标记和空白后作完整子串匹配，再映射回 React 文本节点。跨加粗节点保留原来的加粗；只在原句起点插一次要点圆标。新满足用绿色底，两侧均满足用细绿下划线；没有完整原句就跳过，不按关键词猜。相交的重复标注只保留首个，避免一段文本叠多个高亮。
7. 这些操作只改变展示，数据库回答、判分和 Trace 均未改写。证据抽屉传 `savedEvidence=true`，显示当前题保存的原文快照；Q04 点击后确实显示“较长时间停机……至少每月一次……”的原文。
