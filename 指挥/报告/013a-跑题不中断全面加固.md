## 四个根因核实

| 根因 | 核实结果 | 依据 |
| --- | --- | --- |
| 数据库与进度 JSON 随题数增长争锁 | 对；任务单中的大小须区分统计口径 | 原连接无 WAL、无显式 busy_timeout；每次进度都读写整个 result_json；轻量查询的 json_remove 仍要处理整块 JSON；前端每秒取全详情；监视器每分钟清理。正式库迁移前 A 的 result_json 长 324,033 字符，当前 Baseline 长 2,501,736 字符，这是存储文本字符数，不能直接当 HTTP 响应字节数。 |

## 逐项改动

1. **连接与写锁**：`backend/app/sqlite_support.py` 统一 WAL、synchronous=NORMAL、30 秒 busy_timeout，执行和 commit 遇 locked/busy 逐步等待重试，过程写本机技术日志。应用运行链路的 seed、只读证据验证、Corpus 启动检查、备份读取和复核校准读取均改走统一连接。`providers.py` 将 SQLite 锁明确记为内部存储重试，不再归 Provider permanent。400/401/402/403、明确余额权限错误仍可停整轮；其他状态按本题处理。
2. **每题断点独立保存**：`governance.py` 新增 evaluation_checkpoints / job_checkpoints。Baseline 进度只写当前题和小汇总；候选副本、Golden 各槽原始审计、生成 RPC、Probe/QC、Revision、复核和 Followup 断点分行。完整详情按原结构补回，轻量进度不返回完整断点。复核另存小结论行，保持概览 6 道真错、2 道不稳定的显示。汇总复用同一题内未变的计算；普通心跳 2 秒节流，Provider 请求前后、回答/判分/保存等关键节点立即保存。
3. **读接口与清理**：`main.py`、`read_view.py` 提供评测、实验、Golden、Revision 轻量进度；`api.ts`、`operation.tsx` 和工作页使用轻量轮询，串行请求避免积压，完成或打开详情再取全量。`history.py` 在有评测、生成、修订、Agent 循环或复核时跳过清理；监视器不再每分钟清理，只在适用的启动/作业结束时清理。安全启动只恢复已有授权标记的作业，不做历史维护。
4. **单题故障与已付费响应**：`evaluation.py` / `evaluation_stage.py` 暂时错误先在本题恢复，耗尽后末尾补跑，仍失败才记技术失败，不把该题当业务错题。Provider 自身已耗尽 3 次传输重试时不再嵌套 3 个窗口。生成/评分对象保留后只重试存储；RPC 已完成但持久化回调失败时，即使 Judge 原本 reuse=False，也先保存同一响应而不再次请求。异常监视读取不会把自动作业直接标 stopped；仍保留可恢复状态。主动停止和冻结身份校验保持有效。
5. **Judge**：每题同一遍最多 4 次格式/引用回复，沿用 correction_for，带上上次错误与原回复；末尾补跑仍存在。模型、low 档、提示词版本、判分校验、业务标准均未改。回放预检上界同步为每遍 4 次、含补跑最多 8 次/题，预计一次正常回复/题不变。
6. **Agent 循环与预算**：`optimization_cycle.py` 从断点恢复当前套，再进入下一套；同一故障连续两次续跑仍失败才停。用户停止和 Provider 余额/权限错误立即停。`optimization.py` 在解析方案前保存已收到的原回复，重启复用。治理层复用产品故障对应的逻辑 attempt；中断失败暂不占预算，续跑后 A 仍只计一次，接口统一 evaluation_budget.used。
7. **逐类后台作业**：Golden 生成、Probe、QC 已检查并改为独立 RPC/题目断点；Revision 的材料选择、生成、校验均可复用，manual edit 在 validating 退出后可接着准备；Followup/错题复核从已有题继续，文件只保存小摘要；判分回放走同一加固后的 EvaluationRunner，旧 answer replay 也保存回答断点并支持恢复。D 的 Sandbox 走同一评测、写库、保存与恢复路径，人工确认与发布限制保持原样；本任务没有运行 D，也没有发布或人工确认。
8. **首题前退出**：新 Golden / Revision / 质量重跑、Followup 在创建时就写自动恢复标记，覆盖线程尚未启动就退出的窗口；存活 owner 不接管，待启动 owner 有有限保护期。恢复监视只读小状态，不重新授权旧的未授权历史作业。
9. **两个小后端项**：`golden_v2.py` 与知识库只读投影把文件名回退主题显示为内容语义名，当前 T001 为“设备运行与操作”；原冻结计划与簇成员未改。Probe 新增 question_validity_reason / retrieval_observation，前端分“题目有效”“召回观察”两行，原理由和结论保留。
