## 八个页面说明语

以下每句按任务单原文使用，没有缩写。位置均为对应页面 `.page-purpose`。

| 页面 / 文件 | 改前 | 改后 |
| --- | --- | --- |
| 概览 / `OverviewPage.tsx` | 从知识到上线的完整闭环 | 用一组数字和一条闭环，说明这套系统让智能客服变好了多少，又是怎样一步步做到的。 |
| 知识库 / `KnowledgePage.tsx` | 说明书变成可检索、可追溯的知识 | 把设备说明书解析成可以检索的知识片段，让每一句回答都能追溯到说明书的原页。 |
| Pipeline 配置 / `SettingsPage.tsx` | 固定底座 + Agent 可调的 12 项参数 | 这里放着固定不变的技术底座和 Agent 可以调整的 12 项参数，也就划定了自动优化的边界。 |
| Golden Dataset / `GovernancePage.tsx` | 50 题冻结考卷，每轮用同一把尺子 | 黄金测试集是评测用的标准考卷，50 道题冻结之后，每一轮优化都用它来打分，前后结果才有可比性。 |
| Baseline / `EvaluationPage.tsx` | 当前版本体检：门槛与 Bad Case | 用黄金测试集给当前版本做一次完整体检，看清门槛是否达标、哪些题还答不好、问题出在哪一层。 |
| Agent 工作台 / `EvolutionPage.tsx` | 按 Bad Case 原因提方案、沙盒比较 | Agent 根据 Bad Case 的成因提出不同方向的 Candidate，在 Sandbox 里用同一套考卷比较，找出既修好问题又不弄坏其他题的方案。 |
| 发布 / `VersionsPage.tsx` | 程序给资格，人来批准，可回滚 | 程序只负责判断能不能发布，是否上线由人来批准，每次发布都会保存快照，随时可以回滚。 |
| 问答验证 / `VerificationPage.tsx` | Before / After 的真实回答对比 | 用同一道题优化前后的真实回答做对照，也可以直接向线上版本提问，查看回答和它引用的原文。 |
